# Centro Nacional de Sangue (CNS) — Análise Estatística

Este repositório foi desenvolvido para a disciplina de **Estatística I** como parte do percurso académico do **2ª ano** no **ISPTEC** (Instituto Superior de Politécnico de Tecnologias e Ciências).

O objetivo deste exercício é realizar uma análise estatística descritiva elementar sobre a **frequência cardíaca (em batimentos por minuto - bpm)** registada pelos técnicos do Centro Nacional de Sangue (CNS) numa amostra de estudantes e funcionários do ISPTEC antes da dádiva de sangue.
